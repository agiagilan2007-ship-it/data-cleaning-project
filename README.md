# Employee Data Cleaning and Visualization

This project cleans and explores an employee dataset with **Python, pandas, Matplotlib, and Jupyter Notebook**. It demonstrates a complete workflow from raw CSV data to a cleaned dataset, code outputs, and four different visualizations.

## Project workflow

- Load the raw employee CSV file.
- Check missing values and duplicate rows.
- Fill missing numeric values with medians and missing text values with the mode.
- Convert `Join_Date` to a consistent date format.
- Remove salary outliers using the IQR rule.
- One-hot encode department values.
- Export the cleaned data to `cleaned_data.csv`.
- Create and save a bar plot, scatter plot, line plot, and histogram plot.

## Code outputs

Running the notebook displays:

- Raw and cleaned dataset shapes
- Missing-value counts before and after cleaning
- Number of duplicate rows removed
- Number of salary outliers removed
- A preview of the cleaned dataframe
- Age and salary descriptive statistics
- The four plots shown below

The cleaned output contains **29 employee records and 6 columns**: employee name, age, salary, join date, and one-hot encoded department columns.
