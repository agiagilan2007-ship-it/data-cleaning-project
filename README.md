# Employee Data Cleaning and Visualization

This project cleans and explores an employee dataset with **Python, pandas, Matplotlib, and Jupyter Notebook**. It demonstrates a complete, reproducible workflow from raw CSV data to a cleaned dataset and visual summaries.

## What the project does

- Loads the raw employee CSV file.
- Checks missing values and duplicate rows.
- Fills missing numeric values with the median and missing text values with the mode.
- Converts `Join_Date` to a consistent date format.
- Removes salary outliers using the IQR rule.
- One-hot encodes the department column.
- Exports the cleaned data to `cleaned_data.csv`.
- Creates four visualizations and saves them in `visualizations/`.

## Results and outputs

The cleaned dataset contains **29 employee records and 6 columns**. The exported output includes employee names, ages, salaries, join dates, and one-hot encoded department fields (`Department_hr` and `Department_it`).

The notebook displays these outputs while it runs:

- Missing-value counts before and after cleaning
- Number of duplicate rows removed
- Number of salary outliers removed
- A preview of the cleaned dataframe
- Summary statistics for age and salary
- Four charts: age distribution, salary distribution, department counts, and salary by department

A quick visual summary is available in [VISUALIZATIONS.md](VISUALIZATIONS.md).

## Run the project

```bash
pip install -r requirements.txt
jupyter notebook cleaningdata_final_submission_tested.ipynb
```

Run all notebook cells from top to bottom. The notebook is designed to run from the repository root.

## Main findings

The cleaned data makes it easier to compare employee ages and salaries, inspect department representation, and identify how salaries vary across departments. The charts should be treated as exploratory analysis rather than business conclusions because this is a small sample dataset.
