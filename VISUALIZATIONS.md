## Chart 1: Department Distribution

The code selects every `Department_` column, sums its 0/1 values, removes the prefix from the labels, and plots a bar chart. It shows the number of employees in each encoded department.

![Department distribution](visualizations/department_distribution.svg)

## Chart 2: Salary Distribution

The code plots `cleaned_data['Salary']` in ten bins with black edges and a light horizontal grid. It shows the spread and frequency of salaries after imputation and IQR filtering.

![Salary distribution](visualizations/salary_distribution.svg)

## Chart 3: Salary vs. Age

The Colab code uses `plt.plot` with circular markers and a connecting line. Age is on the horizontal axis and salary is on the vertical axis. This reveals the ordering of the cleaned records and should be read as an exploratory plot, not a fitted relationship.

![Salary versus age](visualizations/salary_vs_age.svg)

## Chart 4: Salary vs. Age by Department

The code loops through the one-hot department columns, creates a mask where each column equals 1, and plots the matching salary and age values as a separate scatter group. The legend identifies Finance, Hr, and It.

![Salary versus age by department](visualizations/salary_vs_age_by_department.svg)

All four charts are regenerated by the notebook. The repository keeps SVG previews for GitHub and PNG output files for local notebook execution.
